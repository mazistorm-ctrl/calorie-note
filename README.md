# カロリーノート

自分専用のカロリー計算・ダイエット記録アプリ。1つのHTMLファイルだけで動きます。

## 使い方

`index.html` をブラウザで開くだけです。記録はブラウザの localStorage に保存されます。

## できること

- 食事の記録（朝食・昼食・夕食・間食）。摂取カロリーとPFC（たんぱく質・脂質・炭水化物）を集計
- 基礎代謝（Mifflin-St Jeor式）× 活動量 − 減量ペース（脂肪1kg＝7,200kcal）で目標カロリーを自動計算
- 体重・運動消費の記録。体重推移と日ごとの摂取カロリーのグラフ（14／30／90日）、目標達成の見込み
- 約45品の食品データ（ひらがな検索対応）、量の倍率、手入力、「よく食べるもの」登録
- ダークモード対応、スマホ幅で使える作り
