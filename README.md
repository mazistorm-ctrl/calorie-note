# カロリーノート

自分専用のカロリー計算・ダイエット記録アプリ。ビルド不要の静的サイト（HTML1枚）で、PWAとしてスマホのホーム画面に追加できます。

## できること

- 食事の記録（朝食・昼食・夕食・間食）。摂取カロリーとPFC（たんぱく質・脂質・炭水化物）を集計
- 基礎代謝（Mifflin-St Jeor式）× 活動量 − 減量ペース（脂肪1kg＝7,200kcal）で目標カロリーを自動計算
- 体重・運動消費の記録。体重推移と日ごとの摂取カロリーのグラフ（14／30／90日）、目標達成の見込み
- 約45品の食品データ（ひらがな検索対応）、量の倍率、手入力、「よく食べるもの」登録
- ダークモード対応、オフラインでも開ける

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML・CSS・JS） |
| `manifest.webmanifest` | PWAの設定（名前・アイコン・表示方法） |
| `sw.js` | オフライン用のService Worker |
| `icons/` | アイコン（`icon.svg` が元データ） |

## データの保存先

記録は、使っている端末のブラウザ内（localStorage）に保存されます。端末ごとに別々のデータで、自動では同期されません。
端末を移したいときは、設定タブの「記録をJSONでコピー」でコピーし、移行先の「記録を取り込む」に貼り付けます。

## Vercelへのデプロイ

Vercelで「Add New → Project」からこのリポジトリをImportし、Framework Presetは「Other」のまま、設定は変えずにDeployします。以降は `main` にpushするたびに自動で更新されます。

アプリを更新したあと、オフライン用のキャッシュを入れ替えたいときは `sw.js` の `CACHE` の番号を上げてください。

## スマホに入れる

- iPhone：Safariで開く → 共有ボタン → 「ホーム画面に追加」
- Android：Chromeで開く → メニュー → 「アプリをインストール」（または「ホーム画面に追加」）
